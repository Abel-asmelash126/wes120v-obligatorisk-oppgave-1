# Mitt WES120V-prosjekt

Dette er et minimalt Vite-prosjekt laget som en del av WES120V.

Prosjektet bruker Vite med Vanilla-template og består foreløpig av en enkel HTML-side.

## Krav

Node.js og pnpm må være installert på maskinen før prosjektet kan kjøres.
## Installasjon

Installer avhengighetene med:

pnpm install
## Oppstart

Start utviklingsserveren med:

pnpm dev

Når serveren har startet, åpner du siden på localhost-adressen som Vite viser i terminalen.
## Om prosjektet

Prosjektet er laget for å øve på Vite, Git og versjonskontroll.
## Stoppe utviklingsserveren

Trykk Ctrl + C i terminalen for å stoppe utviklingsserveren.
Start den igjen med pnpm dev.
